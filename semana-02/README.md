# CERN Preparation Program

Semana 2

## Reflexión sobre Git y GitHub

Durante esta semana aprendí a crear un repositorio, agregar un archivo `README.md`, organizar los avances en varios commits y consultar el historial del proyecto. También comprendí cómo conectar un repositorio local con GitHub y publicar los cambios mediante `git push`.

El comando que me resultó más útil e interesante fue `git log --oneline`, porque permite revisar de forma rápida y clara los commits realizados y comprobar la evolución del proyecto.

La principal dificultad fue entender la relación entre el repositorio local, el remoto `origin` y la rama `main`. Después de revisar la configuración del remoto y el historial, pude sincronizar correctamente el proyecto con GitHub.
